## How the administrator workflow works

1. Ask Codex to check supported sources. Collection and review import run locally, with no scheduler or Google Cloud deployment.
2. Open Proposed Map Updates. Filter by status, meetings, discoveries, uncertainty, jurisdiction, or project name; use paginated results and source coverage details.
3. Review evidence. Status and linked-meeting changes require an individual preview and confirmation. Stale revisions, linked projects, replayed tokens, and changed proposals are blocked.
4. For a possible duplicate or supporting source, enter the existing primary project ID and send it to Potential Duplicates. Nothing is merged by this action.
5. In Potential Duplicates, compare originals, choose canonical fields, preview Merge or Link as Supporting Record, confirm individually, or mark distinct / review later. Applied relationships can be undone when no later changes depend on them.
6. Use Edit Map for verified new developments that still need classification or location information. Discoveries cannot automatically publish themselves.

Research imports preserve original project, account, follow, entitlement, notification, correction, and history tables; backups are taken before metadata imports. Administrator decisions are audited. No new paid services, recurring jobs, bulk merges, or bulk classification were activated.
