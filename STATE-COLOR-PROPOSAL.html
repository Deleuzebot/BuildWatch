Map key

Cluster color = state. Show only the states present in the current view, with full state names and a gray “Multiple states / unknown” item. A collapsed “Map key” control would also explain “Pin color = development status.” Never rely on color alone.

ProposedIn reviewApprovedUnder construction

All existing status definitions, including the retained Completed data type, remain unchanged. The current four status filter chips stay intact.

State boundaries

Keep OpenStreetMap and Apple Maps. Add lazy-loaded, generalized state outlines below the development markers: dark green #334A40, about 0.8 CSS points, opacity 0.45 at national/regional zooms 3–6. Fade to 0.2 by zoom 10 and hide by zoom 12. No state fill, extra labels, county borders, or map-style replacement.

Native and web overlays need a small visual/device trial before finalizing the stroke. Basemap differences may need slightly different opacity. Boundaries would be cached geometry, not project data.

Assignment method and edge cases

Deterministic, committed 50-state assignment, anchored with North Carolina blue. Checked against 108 shared-edge state adjacencies derived from the Census 2026 County Adjacency File, including its water-boundary edges. Point-only contacts are excluded: Arizona and Colorado share amber at Four Corners. Alaska and Hawaii can reuse blue. Proposed count labels meet at least WCAG 4.5:1 contrast.

Cluster colors, the Map key and state outlines were approved and implemented on October 25, 2026. Larger layout changes and automated meeting ingestion remain separate proposals in PERFORMANCE-REPORT.md.
